# Third-party assets and starter material

Threadback begins with the official **SPECS Base Template** created in Lens Studio **5.23.2**, during this hackathon's submission period. This is disclosed starter material; the template is not Threadback's original application functionality.

| Material | Source | Use |
| --- | --- | --- |
| Base scene, camera/render resources, and Echopark environment texture | Lens Studio SPECS Base Template, Snap Inc. | Initial scene and environment lighting. |
| `SpectaclesInteractionKit.lspkg` and associated metadata | Package supplied by the official SPECS Base Template | Standard hand, pinch, and interaction support. |
| `SpectaclesUIKit.lspkg` and associated metadata | Package supplied by the official SPECS Base Template | Standard SPECS UI components. |
| Lens Studio generated agent-reference documents and Git attribute rules | Lens Studio | Tool/API reference and project maintenance. |

Preserve Snap's package and asset notices and comply with their applicable terms. These materials are governed by their own terms; do not relicense them as original Threadback content.

The official Devpost Learn planning skill and Snap CLAD plugin are installed as local development tooling. Their source clones, installer, and local logs are ignored in `artifacts/`. Generated planning output will be committed under `devpost/` after the skill is run.

No additional third-party props, music, or generated assets have been added yet. Extend this record whenever new material is introduced.
